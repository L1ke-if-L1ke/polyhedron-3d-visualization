# Архитектура веб-приложения

## 1. Назначение системы

Веб-приложение предназначено для интерактивной трёхмерной визуализации многогранников с возможностью дальнейшего построения их сечений.

Архитектура приложения предусматривает разделение геометрических данных, визуализации и пользовательского взаимодействия.

Основной принцип разработки — независимость математического представления многогранника от способа его отображения.

## 2. Используемые технологии

| Технология | Назначение |
|---|---|
| TypeScript | Реализация программной логики и описание типов |
| Three.js | Создание и визуализация трёхмерной сцены |
| Vite | Сборка приложения и сервер разработки |
| HTML | Структура пользовательского интерфейса |
| CSS | Стилизация элементов интерфейса |

Текущая версия приложения выполняется на стороне браузера и не требует серверной части.

## 3. Структура приложения

Приложение состоит из следующих логических компонентов:

**Геометрическая модель (`src/geometry/`)**

Содержит описание многогранников и их элементов: вершин, рёбер и граней.

**Модуль визуализации (`src/rendering/`)**

Преобразует геометрические данные в объекты Three.js, пригодные для отображения в трёхмерной сцене.

**Основной модуль (`src/main.ts`)**

Отвечает за создание сцены, настройку камеры, освещения, управление отображением объектов и обработку пользовательских действий.

**Пользовательский интерфейс (`index.html`, `src/style.css`)**

Обеспечивает выбор многогранника и взаимодействие пользователя с приложением.

## 4. Геометрическая модель

Для описания многогранника используется интерфейс `Polyhedron`.

Он объединяет три основных элемента:

- `Vertex` — вершина с именем и координатами.
- `Edge` — ребро, заданное именами двух вершин.
- `Face` — грань, представленная упорядоченным списком вершин.

Координаты вершин хранятся в объектах `THREE.Vector3`.

В текущей реализации предусмотрены две модели:

| Модель | Файл |
|---|---|
| Куб ABCDA1B1C1D1 | `geometry/cube.ts` |
| Правильная четырёхугольная пирамида SABCD | `geometry/pyramid.ts` |

## 5. Механизм визуализации

Для построения поверхностей используется функция `createPolyhedronMesh()` из модуля `polyhedronRenderer.ts`.

Функция получает объект `Polyhedron` и формирует группу объектов Three.js.

Каждая выпуклая грань многогранника разбивается на треугольники, на основе которых создаётся объект `THREE.BufferGeometry`.

Рёбра отображаются с помощью `THREE.LineSegments`, а вершины — небольшими сферическими объектами `THREE.Mesh`.

Для подписей вершин используется `CSS2DRenderer`.

## 6. Управление сценой

В приложении используются:

- `THREE.Scene` — трёхмерная сцена;
- `THREE.PerspectiveCamera` — перспективная камера;
- `THREE.WebGLRenderer` — визуализация геометрии;
- `OrbitControls` — вращение и масштабирование камеры;
- `CSS2DRenderer` — отображение подписей вершин.

Пользователь может переключаться между кубом и пирамидой без перезагрузки страницы.

При переключении предыдущая геометрическая группа удаляется из сцены и заменяется новой.

## 7. Планируемое развитие архитектуры

В следующих этапах разработки предполагается выделение дополнительных компонентов:

**Модуль геометрических вычислений**

Будет отвечать за построение плоскости по трём точкам, вычисление пересечений плоскости с рёбрами и формирование многоугольника сечения.

**Модуль интерактивного выбора точек**

Будет обеспечивать размещение и редактирование точек на рёбрах многогранника.

**Модуль обработки текстовых условий**

Будет использовать API языковой модели для преобразования текстового описания геометрической задачи в структурированные данные.

При этом вычисление сечений будет выполняться собственным геометрическим алгоритмом, независимо от языковой модели.

## 8. Принципы дальнейшей разработки

- Разделение геометрических данных и визуализации.
- Повторное использование универсальных компонентов.
- Минимизация зависимостей между модулями.
- Расширяемость набора поддерживаемых многогранников.
- Постепенное усложнение функциональности без переработки существующей архитектуры.
