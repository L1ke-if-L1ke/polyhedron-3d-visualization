# Математические модели и алгоритмы

## 1. Назначение

Документ содержит описание математических методов, используемых и планируемых к использованию в веб-приложении для интерактивного построения сечений многогранников.

На текущем этапе реализованы представление многогранников в трёхмерном пространстве и построение их поверхностей.

Алгоритмы вычисления секущих плоскостей и сечений запланированы для следующих этапов разработки.

## 2. Представление точки в трёхмерном пространстве

Каждая вершина многогранника задаётся координатами:

\[
P=(x,y,z)
\]

В программной реализации используется тип `THREE.Vector3`.

Например, вершина куба:

```ts
const A = new THREE.Vector3(-1, -1, 1)
```

Такое представление позволяет выполнять векторные операции, необходимые для геометрических вычислений.

## 3. Математическая модель многогранника

Многогранник представляется структурой:

\[
G=(V,E,F)
\]

где:

- \(V\) — множество вершин;
- \(E\) — множество рёбер;
- \(F\) — множество граней.

Каждая вершина имеет уникальное имя и координаты.

Каждое ребро задаётся парой вершин.

Каждая грань задаётся упорядоченной последовательностью вершин, образующих её границу.

В текущей реализации используются выпуклые многогранники.

## 4. Построение поверхностей

Для визуализации поверхностей многогранника применяется триангуляция граней.

Пусть выпуклая грань задана вершинами:

\[
P_0,P_1,\ldots,P_{n-1}
\]

Тогда она может быть представлена набором треугольников:

\[
T_i=(P_0,P_i,P_{i+1}),
\quad i=1,\ldots,n-2
\]

Таким образом, грань с \(n\) вершинами разбивается на \(n-2\) треугольника.

Например, четырёхугольная грань разбивается на два треугольника, а треугольная грань не требует дополнительного разбиения.

Полученные треугольники используются для формирования `THREE.BufferGeometry`.

## 5. Построение плоскости по трём точкам

**Статус: запланировано.**

Пусть заданы три точки:

\[
P_1,\quad P_2,\quad P_3
\]

Сначала определяются два вектора:

\[
\vec a=P_2-P_1
\]

\[
\vec b=P_3-P_1
\]

Нормальный вектор плоскости вычисляется с помощью векторного произведения:

\[
\vec n=\vec a\times\vec b
\]

Если длина нормального вектора равна нулю, точки коллинеарны и не определяют единственную плоскость.

В противном случае плоскость задаётся уравнением:

\[
Ax+By+Cz+D=0
\]

где \(A,B,C\) — координаты нормального вектора.

## 6. Пересечение плоскости с ребром

**Статус: запланировано.**

Ребро многогранника представляется отрезком с концами \(P_0\) и \(P_1\).

Параметрическое уравнение отрезка:

\[
P(t)=P_0+t(P_1-P_0),\quad 0\le t\le1
\]

Для нахождения пересечения с плоскостью координаты \(P(t)\) подставляются в уравнение плоскости.

Если найденное значение параметра удовлетворяет условию:

\[
0\le t\le1
\]

то точка пересечения принадлежит ребру.

Отдельной обработки требуют случаи параллельности ребра плоскости и принадлежности всего ребра плоскости.

## 7. Формирование многоугольника сечения

**Статус: запланировано.**

После определения пересечений секущей плоскости с рёбрами многогранника необходимо:

1. Собрать найденные точки.
2. Удалить совпадающие точки с учётом вычислительной погрешности.
3. Упорядочить точки вдоль границы сечения.
4. Построить многоугольник сечения.
5. Передать полученную геометрию модулю визуализации.

Для выпуклых многогранников сечение плоскостью является выпуклым многоугольником либо вырожденной геометрической фигурой.

## 8. Численная устойчивость

При реализации геометрических алгоритмов необходимо учитывать погрешности вычислений с плавающей точкой.

Для сравнения координат и проверки вырожденных случаев планируется использовать допустимую погрешность \(\varepsilon\).

Например:

\[
|a-b|<\varepsilon
\]

Значение \(\varepsilon\) должно выбираться с учётом масштаба геометрической модели.

## 9. Планируемые алгоритмы

- Построение плоскости по трём неколлинеарным точкам.
- Проверка коллинеарности точек.
- Пересечение плоскости с отрезком.
- Определение точек пересечения плоскости с многогранником.
- Удаление совпадающих точек.
- Упорядочивание вершин сечения.
- Построение и визуализация многоугольника сечения.
- Обработка вырожденных случаев.
