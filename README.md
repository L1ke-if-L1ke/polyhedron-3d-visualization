# Интерактивная 3D-визуализация сечений многогранников

Веб-приложение для интерактивной трёхмерной визуализации многогранников и последующего построения их сечений.

Проект разрабатывается в рамках выпускной квалификационной работы по направлению «Информатика и вычислительная техника».

## О проекте

Цель проекта — разработать образовательный веб-инструмент для изучения стереометрии, позволяющий исследовать геометрические объекты в трёхмерном пространстве и наглядно разбирать построение сечений многогранников.

Приложение использует методы вычислительной геометрии, технологии браузерной 3D-графики и в перспективе — языковые модели для обработки текстовых условий задач.

Разработка ведётся поэтапно: от базового визуализатора многогранников до интерактивной системы построения сечений.

## Реализованные возможности

**3D-визуализация**
- Отображение куба и правильной четырёхугольной пирамиды.
- Вращение и масштабирование камеры с помощью мыши.
- Отображение полупрозрачных граней.
- Отображение рёбер, вершин и их обозначений.
- Переключение между многогранниками без перезагрузки страницы.

**Геометрическая модель**
- Представление многогранников через вершины, рёбра и грани.
- Построение поверхностей из геометрических данных без использования готовых примитивов Three.js.
- Универсальный механизм визуализации многогранников.
- Разделение математической модели и логики отображения.

## Архитектура

В основе приложения лежит структура `Polyhedron`, описывающая многогранник тремя основными компонентами:

| Компонент | Назначение |
|---|---|
| `Vertex` | Именованная точка с координатами в трёхмерном пространстве |
| `Edge` | Ребро, соединяющее две вершины |
| `Face` | Грань, заданная последовательностью вершин |
| `Polyhedron` | Совокупность вершин, рёбер и граней многогранника |

Геометрические модели хранятся отдельно от механизма визуализации.

Модуль `polyhedronRenderer.ts` формирует трёхмерные поверхности из описания граней. Для построения используется триангуляция выпуклых граней с последующим созданием `THREE.BufferGeometry`.

Такой подход позволяет добавлять новые типы многогранников без переработки основного механизма рендеринга.

### Поддерживаемые многогранники

| Многогранник | Вершины | Рёбра | Грани |
|---|---:|---:|---:|
| Куб ABCDA₁B₁C₁D₁ | 8 | 12 | 6 |
| Четырёхугольная пирамида SABCD | 5 | 8 | 5 |

## Технологический стек

- **TypeScript** — основной язык разработки.
- **Three.js** — визуализация трёхмерных объектов.
- **Vite** — сборка и локальный сервер разработки.
- **HTML / CSS** — пользовательский интерфейс.

## Установка и запуск

Для запуска необходимы Node.js и npm.

**1. Клонировать репозиторий**

```bash
git clone <URL_репозитория>
cd geometry-3d
```

**2. Установить зависимости**

```bash
npm install
```

**3. Запустить сервер разработки**

```bash
npm run dev
```

После запуска открыть локальный адрес, указанный Vite в терминале.

**4. Собрать проект**

```bash
npm run build
```

### Основные модули

- `geometry/types.ts` — описание структур геометрических данных.
- `geometry/cube.ts` — математическая модель куба.
- `geometry/pyramid.ts` — математическая модель пирамиды.
- `rendering/polyhedronRenderer.ts` — построение поверхностей многогранников.
- `main.ts` — инициализация 3D-сцены, управление камерой, отображение геометрических объектов и обработка пользовательских действий.
- `style.css` — стили интерфейса и подписей вершин.
