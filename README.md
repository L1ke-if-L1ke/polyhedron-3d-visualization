# Интерактивная 3D-визуализация сечений многогранников

Веб-приложение для интерактивной визуализации многогранников и построения их сечений.

Проект разрабатывается в рамках выпускной квалификационной работы по направлению «Информатика и вычислительная техника».

## Цель проекта

Разработать образовательное веб-приложение, позволяющее визуализировать многогранники в трёхмерном пространстве и интерактивно исследовать построение их сечений.

## Планируемые возможности

- отображение многогранников в 3D;
- вращение и масштабирование модели;
- отображение вершин, рёбер и граней;
- управление прозрачностью граней;
- задание точек на элементах многогранника;
- построение плоскости по трём точкам;
- вычисление и визуализация сечения многогранника;
- отображение вспомогательных построений;
- обработка текстовых условий задач с использованием языковой модели.
